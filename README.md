# 湖上讀行｜大明湖

以 Three.js 製作的第一人稱沉浸閱讀遊戲，供國中生理解劉鶚〈大明湖〉。8 關、25 題，建議 20–30 分鐘，支援電腦及 iPad 觸控操作。

## 學生開啟

使用 GitHub Pages 網址即可遊玩，不必下載、解壓縮或安裝。建議 iPad 橫向、Safari 開啟。首次載入需要網路及支援 WebGL 2 的裝置。

主頁約 6.6 MB，內含使用者提供的背景音樂、課文、題目、路線圖及原創 Blender 白鷺模型。Three.js 0.180.0 與 GLTFLoader 另由 jsDelivr CDN 載入；學校網路必須能存取該 CDN。尚未於實體 iPad/Safari 驗證。

學生進度與證書姓名保存在各自瀏覽器的 localStorage，沒有成績上傳服務。可用遊戲手札匯出／匯入存檔。GitHub Pages 與先前網址屬於不同網站，舊進度請先匯出，再在新網址匯入。

## 操作

- 電腦：WASD 或方向鍵移動、拖曳看景、點按串鈴指示。
- 平板：左下圓盤移動，右側拖曳看景，點按串鈴與選項。
- 船行時依指南針向北或向西划，依課文尋找地點。
- 答錯後可依提示重答；沒有作答倒數。

## 部署與維護

正式網站檔案為 `index.html`，是包含完整遊戲程式與媒體的單檔版本。不需要 npm 安裝或建置。

在儲存庫 Settings → Pages 選擇 Deploy from a branch，分支 main，目錄 / (root)。更新 index.html 後 GitHub Pages 會重新發布。修改後先執行 `node verify.mjs` 檢查程式與題目。發布檔案不含 Sites 憑證或個人存檔。

教材依使用者提供的課文、備課資料與教學需求製作；背景音樂由使用者提供，路線底圖依使用者要求使用備課第167頁。第三方教材及音樂的權利仍屬原權利人；本儲存庫未另授權轉用這些素材。
